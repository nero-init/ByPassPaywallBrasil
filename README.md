# 🛡️ Lista Anti-Paywall (Brasil) – Uso Educacional e Pessoal

> ⚠️ **Aviso legal**: Esta lista é fornecida **apenas para fins educacionais** e de **uso pessoal/local**. Ela não promove nem realiza qualquer redistribuição ou comercialização de conteúdo pago. Os filtros aqui descritos apenas impedem a execução de scripts de bloqueio em seu **próprio navegador**, sem violar direitos autorais ou contratos de uso.

---

## 📌 Como adicionar listas anti-paywall manualmente no AdGuard

1. Abra o **AdGuard**.
2. Vá até **Filtros de Conteúdo** > **Filtros Personalizados**.
3. Clique em **Adicionar filtro**.
4. Dê um nome como: `Anti-Paywall BR`.
5. Cole a lista:
   ```
   https://raw.githubusercontent.com/seu-usuario/seu-repo/main/antipaywall.txt
   ```
   > Você também pode copiar o conteúdo manualmente e colar no editor interno do AdGuard.

---

## 💡 Como funciona?

Essas regras:
- **Impedem scripts de paywall** (como `tinypass`, `matheranalytics`, ou `amp-subscriptions`) de carregarem no navegador.
- **Permitem cookies** apenas quando necessário para visualização do conteúdo.
- **Atuam localmente**, apenas no seu navegador ou rede pessoal, sem modificar os servidores dos sites.

Os filtros funcionam bloqueando padrões conhecidos de URLs, scripts JS e cookies usados por paywalls nos principais veículos de imprensa no Brasil.
